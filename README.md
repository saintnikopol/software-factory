# The Software Factory

A full development lifecycle where **agents run the floor and the human runs the gates**.

<img src="software-factory.svg" alt="The software factory lifecycle: eight stages from intake to reflection, with the two return paths" width="100%">

---------------- 

Factory stats:

 -  **88**  days
 -  **3,024** commits — one per element
 -  **889**  merged PRs — never squashed
 -  **1**  developer in the room

Eight layers, in the order work moves through them. An element cannot skip a stage.
Notice how few operators are still the human — and which ones never stopped being the human.

| # | Stage | Operator |
|---|-------|----------|
| 01 | Intake — goal becomes a graph | Human · agents assist |
| 02 | Design — drafts become decisions | Agent drafts · human OKs |
| 03 | Dispatch — waves into lanes | Agent · gate: interlock |
| 04 | Execution — 1 element = 1 commit | Agent, isolated |
| 05 | Review — fresh context | Agent, read-only |
| 06 | Gates — rule becomes command | Machine, unconditional |
| 07 | Release — stage to main | Human authorises |
| 08 | Reflection — rewrite the manual | Agent writes · human OKs |

Reflection closes the loop along two return paths: new process rules into the standing law,
new engineering work back into the roadmap graph.
